# Google + YouTube 첫 추천 영상

google.com 홈 화면의 구글 로고 자리에 YouTube 홈의 첫 번째(왼쪽 위) 추천 영상을 바로 재생하는 크롬 확장 프로그램입니다. 유튜브 중독자를 위한 기능.

## 동작
- 브라우저의 YouTube 쿠키 그대로 YouTube 홈을 읽어 왼쪽 위 영상부터 후보를 뽑습니다 (광고·쇼츠 제외).
- 홈 피드가 비어 있으면(기록 없는 첫 방문) YouTube 공식 음악 채널 영상으로 대체합니다.
- 음소거로 자동 재생 → 페이지를 처음 클릭하거나 키를 누르면 소리가 켜집니다.
- 퍼가기가 막힌 영상이면 다음 후보로 넘어갑니다.
- `google.com/?stay` 로 들어가면 원래 구글 화면을 유지합니다.

## 설치
1. `chrome://extensions` → 우측 상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 폴더 선택
3. google.com 접속
